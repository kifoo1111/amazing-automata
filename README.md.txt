# 🚀 Amazing Automata - Универсальный CI/CD пайплайн

Простой и мощный инструмент для автоматической сборки, тестирования и деплоя любых проектов.

## 📋 Что умеет этот пайплайн

- 🔍 **Автоматически определяет** тип проекта (Node.js, Python, Java, Go, Rust, Docker и др.)
- 🏗️ **Собирает** проект соответствующим способом
- 🧪 **Запускает тесты** 
- 🔒 **Проверяет безопасность**
- 🚀 **Деплоит** приложение

## 🛠️ Поддерживаемые технологии

| Технология | Файл-индикатор | Сборка | Тесты | Деплой |
|------------|----------------|--------|-------|---------|
| Node.js | package.json | ✅ | ✅ | ✅ |
| Java Maven | pom.xml | ✅ | ✅ | ✅ |
| Python | requirements.txt | ✅ | ✅ | ✅ |
| Go | go.mod | ✅ | ✅ | ✅ |
| Docker | Dockerfile | ✅ | ⚠️ | ✅ |
| Кастомные | .ci-config.yml | ✅ | ✅ | ✅ |
